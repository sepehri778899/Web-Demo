# پورتفولیوی شرکت رای بان داده

وب‌سایت تک‌صفحه‌ای فارسی با React، TypeScript و Vite. فونت‌های Vazirmatn و Poppins به‌صورت محلی بارگذاری می‌شوند و برای انیمیشن‌ها کتابخانه‌ی جداگانه‌ای استفاده نشده است.

## اجرا

```sh
npm install
npm run dev
```

برای ساخت نسخه‌ی Production و پیش‌نمایش آن:

```sh
npm run build
npm run preview
```

## به‌روزرسانی محتوا

- نام برند، لوگو، عنوان‌ها، توضیحات و راه‌های تماس در `src/config/site.ts` قرار دارد.
- پروژه‌ها را در `src/data/projects.ts` اضافه یا ویرایش کنید؛ ترتیب نمایش با `order` تعیین می‌شود.
- تصویرها را در `public/projects/` بگذارید و آدرس آن‌ها را از ریشه، مثل `/projects/example.webp`، وارد کنید.
- برای پروژه‌ای که هنوز دموی در دسترس ندارد، `demoUrl` را `null` بگذارید؛ لینک مشاهده‌ی دمو در این حالت نمایش داده نمی‌شود.
- پیش از انتشار، نشانی نهایی را در `siteUrl` تنظیم کنید تا canonical و `og:url` ساخته شوند.

فونت‌ها و مجوزهای آن‌ها در `public/fonts/` قرار دارند.
